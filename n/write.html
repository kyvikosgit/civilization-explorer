NFC 태그 쓰기

태그 하나에 주소 하나. 폰을 태그에 대면 그 주소의 체험 화면이 열립니다. 주소는 짧게 두고, 어디로 열릴지는 사이트에서 바꿉니다.

아이폰으로 쓰기

  1. 앱스토어에서 NFC Tools(wakdev) 설치
  2. 아래 목록에서 복사
  3. NFC Tools → 쓰기 → 레코드 추가 → URL/URI → 붙여넣기 → 확인
  4. 쓰기를 누르고 폰 윗부분을 태그에 댄다

안드로이드(크롬)로 쓰기

이 페이지를 크롬에서 열고 태그에 쓰기를 누른 뒤 폰 뒷면을 태그에 댑니다.

읽기

아이폰(XS 이후)은 화면이 켜져 있으면 앱 없이 태그를 읽습니다. 화면 위에 뜨는 알림을 누르면 열립니다. 안드로이드는 NFC가 켜져 있으면 바로 열립니다.
NTAG213·215·216 태그를 쓰세요. MIFARE Classic(교통카드·출입카드류)은 아이폰이 읽지 못합니다.

주소 연결은 /n/index.html 에서 관리합니다.
